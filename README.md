# KeyboardFight

Apprendre à taper au clavier en combattant. Une appli web locale, sans backend, pour un enfant de 9 ans (TDAH) qui révise aussi l'orthographe de ses listes de mots.

- Chaque bonne touche est un coup. Cinq bonnes touches rapides font un combo. Un mot sans faute fait un PERFECT. Une erreur déclenche une riposte.
- Précision avant vitesse. Sessions courtes. Aucun chrono punitif.
- Tout reste dans le navigateur : aucune donnée ne quitte l'ordinateur.

## Démarrer

```bash
npm install
npm run dev     # http://localhost:5173/keyboardfight/
npm test
npm run build
```
